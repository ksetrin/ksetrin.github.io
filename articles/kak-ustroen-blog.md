Этот пост одновременно демонстрация оформления и инструкция. Если ты его видишь в блоге — значит, движок собрал markdown в страницу.

## Как добавить статью

Один пост — это один markdown-файл в папке `articles/`. Никакой админки и базы данных.

1. Создай файл `articles/my-post.md`.
2. В начале добавь frontmatter (метаданные между `---`).
3. Запусти `npm run dev` — пост сразу появится в ленте.
4. Для публикации: `npm run build` собирает статические страницы, sitemap и RSS, затем деплой на GitHub Pages.

Минимальный frontmatter выглядит так:

```yaml
---
title: "Заголовок поста"
description: "Короткое описание для ленты и SEO."
tags: ["rag", "agents"]
slug: "my-post"
lang: "ru"
datePublished: "2026-06-27"
author: "Пётр Евсиков"
tldr: ["Тезис один", "Тезис два"]
---
```

После frontmatter — обычный markdown. Имя файла и `slug` дают адрес: `/articles/my-post/`.

## Что умеет оформление

### Текст и ссылки

Работает **полужирный**, *курсив* и `инлайн-код`. Ссылки выглядят так: [главная блога](/) или [внешний сайт](https://example.com). Длинные абзацы держат комфортную ширину строки для чтения.

### Блоки кода с подсветкой

Код подсвечивается автоматически по указанному языку:

```python
from pydantic import BaseModel

class QA(BaseModel):
    question: str
    answer: str

def extract(text: str) -> list[QA]:
    # вызов локальной модели через Ollama
    return run_llm(text, schema=QA)
```

И команды в шелле:

```bash
ollama run qwen3:30b-a3b "Сделай выжимку из этого транскрипта"
```

### Списки

Маркированный список:

- первый пункт
- второй пункт с `кодом`
- третий пункт

Нумерованный — выше, в разделе про добавление статьи.

### Цитата

> Дисциплина бьёт талант: один артефакт и один пост в день. Через 90 дней это уже система, а не намерение.

### Таблица

| Этап        | Инструмент      | Результат                |
|-------------|-----------------|--------------------------|
| Инференс    | Ollama / MLX    | локальный ответ модели   |
| Retrieval   | Chroma + BM25   | релевантные чанки        |
| Оценка      | Ragas           | faithfulness, recall@k   |

### Изображения

Картинки вставляются стандартным синтаксисом markdown:

```markdown
![Подпись к картинке](/путь/к/картинке.png)
```

### Оглавление и TL;DR

Заголовки уровня `##` и `###` автоматически собираются в оглавление слева от текста, а блок TL;DR берётся из frontmatter. Время чтения считается по объёму автоматически.
